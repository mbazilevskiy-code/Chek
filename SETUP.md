# Переезд на Claude Code + GitHub — пошагово

Разовая настройка минут на 20. После неё: правишь код в Claude Code словами, говоришь
«опубликуй» — и он сам сохраняет копию в GitHub и обновляет сервер. Архивы больше не нужны.

Если на каком-то шаге застрял — пришли скриншот в чат Cowork, разберём.

## Что понадобится (ставится один раз)

1. **Аккаунт GitHub** — github.com, кнопка Sign up (бесплатно, 2 минуты).
2. **Git** — скачать с git-scm.com, установить со всеми галочками по умолчанию.
3. **Node.js** — nodejs.org, версия LTS (нужна для Claude Code).
4. **Claude Code** — после установки Node открой терминал (на Windows — «PowerShell»)
   и выполни: `npm install -g @anthropic-ai/claude-code`
   (точную команду установки всегда можно проверить в документации Claude Code).

## Шаг 1. Положи проект в папку

Распакуй этот архив в постоянное место, например `Документы/chek`. Это теперь «дом»
проекта — отсюда больше ничего никуда таскать не надо, Claude Code правит файлы прямо тут.

## Шаг 2. Создай приватный репозиторий на GitHub

1. На github.com нажми **New repository**.
2. Имя: `chek`. Выбери **Private** (важно — код и логика приватные).
3. НЕ добавляй README/gitignore (они уже есть в проекте). Нажми **Create repository**.
4. GitHub покажет адрес репозитория вида `https://github.com/ТВОЙ_ЛОГИН/chek.git` — скопируй.

## Шаг 3. Открой проект в Claude Code и запусти первую загрузку

1. Открой терминал в папке проекта (в проводнике: правой кнопкой по папке → «Открыть в
   терминале», либо `cd путь/к/папке`).
2. Запусти `claude` — откроется Claude Code уже в этой папке.
3. Скажи ему словами, например:
   > Инициализируй git, сделай первый коммит и запушь в мой приватный репозиторий:
   > https://github.com/ТВОЙ_ЛОГИН/chek.git — проверь, что .env и база в .gitignore и НЕ уходят.
4. Claude Code всё сделает и попросит войти в GitHub, если нужно.

⚠️ **Важно про секреты:** файл `.env` (с твоими ключами) и `food_diary.db` уже в `.gitignore`
— они остаются только у тебя и НЕ попадают в GitHub. Не убирай их оттуда.

## Шаг 4. Как работать дальше (каждый день)

1. Открываешь терминал в папке проекта, запускаешь `claude`.
2. Говоришь, что доделать («добавь в кабинет тренды анализов», «поправь текст в /start»…).
3. Он пишет код. Проверить можно попросив его прогнать `python test_local.py`.
4. Говоришь **«опубликуй»** — Claude Code сохраняет копию в GitHub и выкатывает на сервер.
   (Процедура публикации описана в `CLAUDE.md`, он её знает. IP сервера держи под рукой —
   он спросит в первый раз.)

## Про сервер (ничего не меняется)

Твой сервер на Timeweb как работал 24/7, так и работает — это «кухня», где живёт бот.
GitHub — «сейф» с копией кода. Публикация обновляет сервер и кладёт копию в сейф за одно
действие. Сервер, база с дневниками, боты тренеров — всё остаётся как есть.

## Подсказки

- Cowork (обычный чат с Клодом) остаётся для стратегии, документов, макетов, презентаций.
  Claude Code — для кода. Оба смотрят в один проект.
- Полный контекст проекта — в `CLAUDE.md`. Claude Code читает его сам.
- Обновить контекст после больших изменений: попроси Claude Code дописать `CLAUDE.md`.
