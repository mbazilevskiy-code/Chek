# 🥗 Фуд-бот: калории, БЖУ и оценка по Полу Чеку

Личный Telegram-бот. Присылаешь фото еды — получаешь калории, белки/жиры/углеводы,
оценку блюда по принципам Пола Чека («How to Eat, Move and Be Healthy») и итог за день.

Что умеет:

- 📸 Анализ еды по фото (подпись типа «борщ со сметаной, 400 г» делает расчёт точнее)
- ✍️ Анализ по текстовому описанию: «2 яйца, тост с маслом, кофе с молоком»
- 🌿 Оценка каждого блюда по Чеку от 1 до 10 + совет, как улучшить
- 💧 Трекер воды с нормой по Чеку (~0,033 л на кг веса): пиши «вода 300» или жми кнопки
- 🧘 Working In — отметка восстановительных практик (дыхание, зоновые упражнения), серии
- 🏋️ Тренировки на турнике и брусьях: `/plan пн,ср,пт 18:00` — расписание с напоминаниями,
  `/train` — Claude генерирует программу по Чеку под твой профиль
- 🌙 Вечерняя сводка дня (время — `/reminders 21:30`, выключить — `/reminders off`)
- 🖥 Десктоп-дашборд в браузере: `http://localhost:8127` — вся картина за 7/30 дней
  с графиками и журналом (работает, пока бот запущен)
- 📊 Дневник: `/today` — весь день, `/week` — неделя, `/undo` — удалить последнюю запись еды
- 🎯 Личная норма КБЖУ и воды: анкета `/profile` или вручную `/targets 2000 150 70 200`

Токен Telegram уже вписан в файл `.env` — бота можно запустить прямо сейчас, вообще
без ключей ИИ (он стартует в **демо-режиме**: приём фото и все команды работают,
анализ еды выключен). Чтобы включить анализ, нужен один ИИ-ключ — есть бесплатный
вариант, см. шаг 2.

---

## Шаг 1. Установи Python (если ещё нет)

- **Windows:** скачай с [python.org/downloads](https://www.python.org/downloads/) и запусти
  установщик. **Обязательно поставь галочку «Add python.exe to PATH»** на первом экране.
- **Mac:** скорее всего Python уже есть. Если нет — с того же сайта.

## Шаг 2. Выбери ИИ для анализа еды

### Вариант А — Claude (рекомендуется, точнее всего)

1. На **console.anthropic.com** в разделе **Billing** пополни баланс (от $5 — хватит
   на сотни фото), в разделе **API Keys** нажми **Create Key** и скопируй ключ
   (начинается с `sk-ant-`). ⚠️ Ключ показывается один раз — сразу сохрани.
2. Открой файл `.env` в этой папке (обычным Блокнотом) и вставь ключ в строку
   `ANTHROPIC_API_KEY=`.

Одно фото ≈ $0.01–0.02 (пополнения на $5 хватит на несколько месяцев дневника).
Дешевле — поменяй в `.env` модель на `claude-haiku-4-5`.

### Вариант Б — запасной, бесплатно и без карты (OpenRouter)

1. Зайди на **openrouter.ai** и зарегистрируйся (почта, Google или GitHub — карта не нужна).
2. В меню открой **Keys** → **Create Key**, скопируй ключ (начинается с `sk-or-`).
3. Вставь его в `.env` в строку `OPENROUTER_API_KEY=`.

Бот сам подберёт бесплатную модель с поддержкой фото (`OPENROUTER_MODEL=auto`).
У бесплатных моделей есть дневной лимит запросов (порядка 50–200 в день — для дневника
хватает) и точность заметно ниже Claude. Если заполнены оба ключа, бот выберет Claude.

## Шаг 3. Запусти бота

1. **Обязательно распакуй архив**: правой кнопкой по zip → «Извлечь всё» — и работай
   с распакованной папкой (из окна архива скрипт не запустится).
2. **Windows:** двойной клик по `start_windows.bat` в распакованной папке.
   **Mac:** открой Терминал, набери `bash `, перетащи в окно файл `start_mac_linux.sh` и нажми Enter.
3. Скрипт сам установит всё нужное (около минуты) и напишет: `✅ Бот @твой_бот запущен`,
   а ниже — какой ИИ подключён (или предупреждение про демо-режим).

Открой своего бота в Telegram, нажми **Start** — и пришли фото еды 📸

> Бот работает, пока открыто окно скрипта. Закрыл окно — бот уснул; запусти скрипт снова.
> Чтобы работал 24/7 без компьютера — см. раздел «Переезд на сервер» ниже.

## Как пользоваться

| Действие | Что делать |
|---|---|
| Записать приём пищи | Пришли фото (лучше сверху и сбоку, чтобы был виден объём) |
| Уточнить расчёт | Добавь подпись к фото: вес, состав, «без масла» и т.п. |
| Записать без фото | Просто напиши текстом, что съел |
| Отметить воду | Напиши «вода 300» или открой `/water` и жми кнопки |
| Working In | `/habits` → кнопка «Working In сделал» |
| Тренировка сегодня | `/train` — программа на турнике/брусьях по Чеку, после — кнопка «Сделал» |
| Расписание тренировок | `/plan пн,ср,пт 18:00` (бот напомнит), убрать — `/plan off` |
| Напоминания и сводка | `/reminders` — статус, `/reminders 21:30` — время, `off`/`on` |
| Итог за день | `/today` — еда, вода, Working In, тренировка |
| Неделя | `/week` |
| Ошибся / задвоилось | `/undo` — удалит последнюю запись еды |
| Настроить нормы | `/profile` (анкета), `/targets 2000 150 70 200`, `/water цель 2500` |

**Напоминания** (о тренировках и вечерняя сводка) приходят, только пока бот запущен
на компьютере. Выключен компьютер — напоминание не придёт.

## Десктоп-дашборд

Оперативные вещи — в Telegram, а вся системная картина — в браузере на компьютере.
Пока бот запущен, открой **http://localhost:8127** (адрес печатается в окне бота
при старте). Удобно закрепить вкладку или сделать ярлык.

Что на дашборде: плитки дня (калории, вода, средний Чек, тренировки, серия Working In),
графики по дням за 7 или 30 дней (калории с линией цели, вода, оценка по Чеку)
и журнал еды по дням. Данные обновляются сами раз в минуту, есть кнопка «Обновить».

Приватность: страница доступна **только с этого компьютера** (localhost) и читает
локальную базу `food_diary.db` — в интернет ничего не уходит.
Отключить дашборд: `DASHBOARD=off` в `.env`; поменять порт: `DASHBOARD_PORT=8128`.

## Переезд на сервер (бот работает 24/7)

После переезда бот и напоминания работают всегда, даже при выключенном компьютере,
а дашборд открывается по секретной ссылке с любого устройства — и с телефона тоже.

### Шаг А. Заведи сервер (~5 минут, ~300–500 ₽/мес)

1. Зарегистрируйся у российского хостера с зарубежными локациями —
   например **Timeweb Cloud** (timeweb.cloud) или **Aeza** (aeza.net). Оплата рублями.
2. Создай самый дешёвый облачный сервер:
   - **Локация: Нидерланды или Германия** — это важно, из российской локации
     Claude API не работает;
   - ОС: **Ubuntu 24.04**;
   - минимальная конфигурация (1 CPU / 1 ГБ RAM достаточно).
3. После создания хостер покажет **IP сервера** и **пароль root** (в панели или письме).

### Шаг Б. Запусти деплой (1 клик)

1. Двойной клик по `deploy_windows.bat` в папке бота.
2. Введи IP сервера. Пароль root спросится несколько раз — это нормально.
3. Скрипт сам скопирует файлы, настроит службу с автозапуском, переведёт сервер
   на московское время и напечатает **ссылку на дашборд** вида
   `http://IP:8127/?key=...` — сохрани её в закладки (работает и на телефоне).
4. **Закрой окно локального бота** на компьютере — два бота одновременно мешают
   друг другу.

Дневник `food_diary.db` переносится на сервер при первом деплое. При повторных
деплоях (обновление кода) серверный дневник **не затирается** — просто снова
запусти `deploy_windows.bat`.

Полезное на сервере: логи — `journalctl -u chek-bot -n 50`,
перезапуск — `systemctl restart chek-bot`.

⚠️ Безопасность: доступ к дашборду защищён ключом в ссылке — не публикуй её.
Соединение пока по http (без шифрования); https добавим на следующем этапе.
Если команда `ssh` не найдена — включи «OpenSSH Client» в
Параметры → Приложения → Дополнительные компоненты.

## БАДы, самочувствие, анализы

**💊 БАДы** — `/supplements` (или `/bad`): добавляешь название и время приёма, отмечаешь
принятые за день кнопками. «🔍 Совместимость» — ИИ проверит весь набор на конфликты
(например, кальций мешает железу) и подскажет по времени приёма. Справочно, не назначение.

**🙂 Самочувствие** — `/feel`: быстрый опрос по шкале 1–10 (энергия, настроение, стресс,
либидо — можно пропустить) плюс заметка. Вечерняя сводка предлагает отметиться в один тап.
Данные копятся, чтобы потом видеть связи с едой и сном.

**🧪 Анализы** — пришли боту **PDF или фото бланка** любой лаборатории (или `/labupload`):
ИИ распознает показатели, единицы и нормы, подсветит вышедшее за референс и запомнит.
`/labs` — что вне нормы и динамика; `/labreport` — разбор с рекомендациями образа жизни
и вопросами к врачу. PDF разбирается на Claude; фото — на любой модели. Не диагноз —
интерпретация за врачом.

## Кольцо Oura (сон, готовность, HRV)

Подключается один раз и дальше тянет данные само. Нужна разовая регистрация приложения.

### Настройка приложения (владелец, ~10 минут)

1. Зайди на **cloud.ouraring.com** под своим аккаунтом Oura → раздел для разработчиков
   (**Create a new OAuth2 Application**).
2. В поле **Redirect URI** впиши точно: `http://<IP-сервера>:8127/oura/callback`
   (тот же IP, что в ссылке дашборда).
3. Скопируй **Client ID** и **Client Secret**.
4. На сервере в `.env` заполни `OURA_CLIENT_ID`, `OURA_CLIENT_SECRET` и
   `OURA_REDIRECT_URI` (тот же адрес callback), затем перезапусти бота (повторный деплой).

### Подключение кольца (каждый пользователь)

В боте команда **/oura** → кнопка «Подключить Oura» → разрешаешь доступ на сайте Oura →
возвращаешься в Telegram. Дальше сон, готовность и HRV каждое утро подтягиваются сами и
появляются в /today, дашборде, кабинете тренера и брифах. Обновить вручную — `/oura_sync`,
отключить — `/oura_off`.

> Если при регистрации приложения Oura потребует HTTPS для Redirect URI — напиши мне,
> добавим бесплатный сертификат (это отдельный небольшой шаг).

## Чек Про: подключение тренера (white-label)

У каждого тренера — свой бот под его брендом и веб-кабинет со «светофором» по клиентам
и AI-брифами. Подключение:

1. **Бот тренера.** Тренер (или ты за него) создаёт бота у @BotFather: `/newbot` →
   имя (например «Ассистент Анны») → юзернейм → скопировать токен.
2. **Регистрация.** В **твоём личном боте** команда `/newcoach` → пришли токен → имя
   тренера → название сервиса. Бот выдаст **ключ кабинета** и перезапустится
   (на сервере это автоматически, ~5 секунд).
3. **Привязка тренера.** Тренер пишет своему боту `/start` — первый написавший
   становится владельцем этого бота. В ответ бот пришлёт ему ссылку на кабинет
   и ссылку для клиентов.
4. **Клиенты.** Тренер отправляет клиентам ссылку `t.me/<его_бот>`. Клиент жмёт Start,
   бот здоровается от имени тренера и просит **согласие** на доступ тренера к данным —
   без согласия ничего не записывается и тренер ничего не видит.
5. **Кабинет** — `http://IP-сервера:8127/coach?key=КЛЮЧ`: список клиентов со светофором
   (кто молчит, у кого качество еды упало, кто недоедает), недельная картина каждого
   и кнопка «AI-бриф» — сводка недели + готовый черновик сообщения клиенту.

Команда `/clients` в боте тренера показывает краткий список прямо в Telegram.

## Как обновиться с прошлой версии, не потеряв дневник

1. Останови старого бота (закрой его окно).
2. Распакуй новую версию в новую папку.
3. Перенеси из старой папки в новую файл `food_diary.db` (твой дневник).
   Если менял что-то в `.env` (например, ALLOWED_USER_IDS) — перенеси и его.
4. Запусти `start_windows.bat` из новой папки. База сама дополнится новыми таблицами,
   все записи еды сохранятся.

## Точность

Оценка по фото — приблизительная (обычно ±20–30%): нейросеть не видит вес и скрытое масло.
Бесплатные модели OpenRouter ошибаются заметнее Claude. Для трекинга тренда за
день/неделю этого достаточно, а подпись с весом сильно повышает точность.

## Приватность и доступ

- Дневник хранится **только на твоём компьютере** в файле `food_diary.db`.
- Бот личный: он привязывается к первому написавшему (к тебе). Чтобы дать доступ
  жене/другу — впиши их Telegram ID через запятую в `ALLOWED_USER_IDS` в файле `.env`
  и перезапусти бота (свой ID бот показывает тому, кому отказал в доступе).
- Фото уходят только в выбранный ИИ-сервис (OpenRouter или Anthropic) для анализа.

## Если что-то не работает

- **«Python не найден»** — шаг 1; на Windows не забудь галочку PATH и после установки
  запусти скрипт заново.
- **«Telegram не принял токен»** — проверь `TELEGRAM_BOT_TOKEN` в `.env`: без пробелов,
  без кавычек, целиком.
- **Бот отвечает про демо-режим** — в `.env` не заполнен ни один ИИ-ключ (шаг 2),
  либо бот не перезапущен после заполнения.
- **«OpenRouter не принял ключ»** — проверь `OPENROUTER_API_KEY`: без пробелов и кавычек.
- **«Дневной лимит OpenRouter исчерпан»** — бесплатные модели ограничены по числу
  запросов в сутки; попробуй позже.
- **«Модель OpenRouter недоступна»** — поставь `OPENROUTER_MODEL=auto` в `.env`.
- **«Anthropic не принял API-ключ» / «закончились средства»** — проверь ключ и Billing
  на console.anthropic.com.
- **«Доступ запрещён» от ИИ-сервиса** — сервис недоступен из твоей сети; включи VPN,
  который работает для всего компьютера, и перезапусти бота.
- **Бот молчит в Telegram** — окно скрипта закрыто? Запусти его снова.
